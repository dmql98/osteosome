## 依赖关系

```
P1a ─► P1b ─► P2 ─► P3 ─► P4 ─► P5 ─► P6 ─► P7 ─► P8
```

- **P3（Loop）是 P5-P7 的宿主**：角色 / 技能 / MCP 都挂在它上面。
- **P2 写死单 provider，但 wire 走中立流契约**，P4 只换 providers 层，不重写骨架。
- **P1-P4 = 基座**（2026-09-23 评估定案）：P1a 补 2 处小补强；P1b 加通用组件库；P2 落 DSH 接缝三角；P3 加会话存储；P4 加凭证 seam + 设置 Pane——各阶段扩展 30~50%，周期已相应上调（见总览）。
