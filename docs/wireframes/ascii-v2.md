> 状态：设计稿 ｜ 作者：dmql ｜ 日期：2026-09-25
> 关联：`index.html`（线框 v1）、工作台前端设计文档

## 0. 阅读约定

| 符号 | 含义 |
|---|---|
| `┌─┐└┘├┤┼` | 界面框线（Panel / 容器） |
| `═ ║` | 强调分隔（页头 / 主要分区） |
| `▶` | 当前激活 / 高亮 |
| `○ ● ◉` | 关闭 / 开启 / 运行中 |
| `▸ ▾` | 折叠 / 展开 |
| `[ ... ]` | 按钮 / 可点击区域 |
| `( )` | 单选 / 多选 |
| `···` | 内容截断 |
| `▓` | 高亮 / 拖拽中的 ghost |
| `░` | Drop 目标预览 |

## 1. 全局状态总览

Osteosome 前端有 **3 个正交维度**，组合出主要状态：

```
┌─ 维度 1：模式（editorStore.mode）──────────────┐
│  ● runtime（默认，用户使用）                    │
│  ○ edit（编辑，装配布局）                       │
└────────────────────────────────────────────────┘

┌─ 维度 2：装配区（editorStore.assemblyOpen）──────┐
│  ● 关闭（默认 runtime）                           │
│  ○ 打开（仅 edit 模式，主窗左栏=面板装配区）      │
└────────────────────────────────────────────────┘

┌─ 维度 3：内容状态（各 Panel 独立）─────────────┐
│  ● empty（新建，无组件）                        │
│  ○ 部分装配                                     │
│  ○ 全装配                                       │
│  ○ 加载中 / 错误                                │
└────────────────────────────────────────────────┘
```

**9 个核心屏幕**（本文逐一画）：

```
A. 主窗 · 运行态（正常使用）
B. 主窗 · 编辑态（装配区展开）
C. 主窗 · 空状态（首次启动）
D. 插件管理（独立原生窗口）
E. Panel · 三种类型（空 / 内容 / 画布）
F. Canvas 内组件 · 四种状态
G. 装配交互 · 拖拽 / 点击 / Drop
H. 弹窗 · 确认 / 选择 / 进度
I. 状态指示 · 服务 / 加载 / 错误
```

## A · 主窗 · 运行态（正常使用）

> ⚠ 运行态布局 = **用户自己装配的面板**，无系统固定侧栏。下图「会话」「服务状态」只是**用户碰巧放进去的两个组件面板**（示例），不是系统内置。运行态只有顶栏（含两个入口按钮），主体全是用户装配的 dockview 布局。

```
╔═ Osteosome ═════════════════════════════════ [编辑] [插件] ══╗
║                                                          ║
║  ┌─ 对话 ────────────────────────────────────────────┐  ║
║  │                                                    │  ║
║  │  ┌──────────────────────────────────────────────┐ │  ║
║  │  │ [我] 帮我写个 Python 脚本                     │ │  ║
║  │  └──────────────────────────────────────────────┘ │  ║
║  │  ┌──────────────────────────────────────────────┐ │  ║
║  │  │ [Agent] 好的，这是一个读取 CSV 的示例：       │ │  ║
║  │  │         ```python                             │ │  ║
║  │  │         import csv                            │ │  ║
║  │  │         with open('data.csv') as f:           │ │  ║
║  │  │             reader = csv.reader(f)            │ │  ║
║  │  │             for row in reader:                │ │  ║
║  │  │                 print(row)                    │ │  ║
║  │  │         ```                                   │ │  ║
║  │  └──────────────────────────────────────────────┘ │  ║
║  │                                                    │  ║
║  │  ┌────────────────────────────────────────────────┐│  ║
║  │  │ [📎 附件]  [🎛 deepseek-chat ▾]      [发送]    ││  ║
║  │  └────────────────────────────────────────────────┘│  ║
║  └────────────────────────────────────────────────────┘  ║
║                                                          ║
║  ┌─ 会话 ──────────┐   ┌─ 服务状态 ───────────────┐     ║
║  │ [＋ 新建]        │   │ ● core     v3.0  ready   │     ║
║  │ ▶ 帮我写脚本     │   │ ● llm      v1.0  ready   │     ║
║  │   10 分钟前      │   │ ● loop     v1.0  ready   │     ║
║  │   昨天的对话     │   │ ● session  v1.0  ready   │     ║
║  │   上周的调研     │   │ ● character v1.0 ready   │     ║
║  └─────────────────┘   └──────────────────────────┘     ║
║                                                          ║
╚══════════════════════════════════════════════════════════╝
```

**顶栏两个入口（分开）**：
- `[编辑]` → 切到编辑模式（主窗解冻 + 打开面板装配区）
- `[插件]` → 打开插件管理（独立原生窗口，见 D）

**要点**：
- 顶栏极简：应用名 + `[编辑]` `[插件]` 两个入口
- Panel 无常驻标题栏；鼠标悬停到面板顶部时，**浮现悬浮顶栏**（毛玻璃，自动隐藏），仅两个按钮：`⤢ 拉出独立窗` `× 关闭`
- 组件无边框、无把手（`mode === 'runtime'`）
- 组件照常交互（输入、点击、滚动）

## B · 主窗 · 编辑态（侧栏=面板装配区）

> 插件管理不在主窗侧栏（它是独立窗口，见 D）。编辑态主窗左栏是**面板装配区**：已有面板列表 + 可拖组件库。

```
╔═ Osteosome · 编辑模式 ═══════ [退出编辑 Esc] [编辑] [插件] ══╗
║                                                          ║
║  ┌─ 面板装配区 ─┐  ┌─ 对话（Panel 1）─────────────────┐  ║
║  │ 已有面板      │  │ ┌──────────────────────────────┐ │  ║
║  │  ▶ 对话     │  │ │ ▓ 消息框（未选中·虚线）        │ │  ║
║  │    分析      │  │ │   [我] ...                    │ │  ║
║  │    仪表盘    │  │ │   [Agent] ...                 │ │  ║
║  │ [+ 新建面板] │  │ │                     ⤡        │ │  ║
║  │              │  │ └──────────────────────────────┘ │  ║
║  │ ── 组件库 ──  │  │ ┌──────────────────────────────┐ │  ║
║  │ ✨ 消息框     │  │ │ ▓ 发送按钮（选中·实线）       │ │  ║
║  │ ✨ 模型选择   │  │ │   [发送]                     │ │  ║
║  │ 📎 附件按钮   │  │ └──────────────────────────────┘ │  ║
║  │ ⚙ 服务状态   │  │ ↑ 组件：未选中虚线 / 选中实线高亮 │  ║
║  │ 💬 会话列表   │  └─────────────────────────────────┘  ║
║  │ 📈 LLM 统计   │                                       ║
║  │  ⋮ 拖到面板   │  ┌─ 分析（Panel 2）─────────────┐    ║
║  │              │  │ ┌──────────────────────────┐  │    ║
║  │ ── 来源 ──   │  │ │ 本地路径（未装配）        │  │    ║
║  │ 各插件贡献    │  │ │  ┈┈ 拖组件到此处 ┈┈       │  │    ║
║  │ 自己的组件    │  │ └──────────────────────────┘  │    ║
║  └──────────────┘  └─────────────────────────────────┘    ║
║                                                          ║
║  ● 编辑模式：Panel 可拖/分组，组件可拖/缩放/选中           ║
╚══════════════════════════════════════════════════════════╝
```

**要点**：
- 顶栏显示「编辑模式 + 退出编辑 + Esc 提示」，`[编辑]` 高亮、`[插件]` 仍在
- 左侧是**面板装配区**（不是插件管理窗口）
- Panel 顶栏：**悬停浮现**（毛玻璃，自动隐藏），仅 `⤢ 拉出` `× 关闭` 两按钮（编辑态可同时拖拽面板/分组）
- 组件：**未选中**虚线边框 / **选中**实线高亮 + 右上角缩放把手 `⤡`
- 空白 Panel 显示「拖组件到此处」占位

## M · 下一步实现优先级

按**先跑通骨架，再做细节**的顺序：

| 优先级 | 界面 | 阶段 |
|---|---|---|
| **P0** | A（运行态）+ B（编辑态）+ E1（空 Panel）+ G1（拖拽装配） | **P1b + 1.5d** |
| **P1** | C（空状态）+ E2（内容 Panel）+ I1（服务状态） | P1b + 3d |
| **P2** | D1-D3（插件管理）+ F1-F2（组件编辑/选中）+ H1（卸载确认） | P5 前后 |
| **P3** | E3（多组件画布）+ G2（点击装配）+ H2-H3（新建/安装） | P5 前后 |
| **P4** | F3-F4（拖拽中/多选）+ I3-I4（加载/错误）+ H4（错误） | 远期 |
| **P5** | J 快捷键 / K 命名约定 落地 | 随阶段 |

## 一句话

> **每个屏幕、每个状态都用 ASCII 画清——从主窗运行态到插件管理独立窗口，从 Panel 三种类型到 Canvas 内组件四种状态，从装配交互到弹窗错误。**
>
> **P0 是骨架（A/B/E1/G1），P1 是空态与内容（C/E2/I1），P2-P5 逐步补全。**
>
> **实现顺序与阶段对齐：P1b + 1.5 天先跑 P0；P5 前后做完整插件管理。**
